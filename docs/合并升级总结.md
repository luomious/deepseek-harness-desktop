# DSH 合并升级总结

> 日期:2026-08-22 | 状态:核心完成,观察期中 | 详细执行记录见 `docs/升级执行记录.md`,机制见 `docs/隔离与移植机制.md`

## 一、做了什么

1. **修复 D 盘插件 6 处崩溃点**(独立提交,可单独回滚):
   remote-workspace(流级 error 监听 + handle try/catch)、session-watchdog(resume 挂 catch)、
   context-lifecycle(pendingTimer 兜底)、stuck-loop-guard(next 挂 catch + WeakMap 判对象)、
   vision-engine(轮询幂等清理)、project-brief(文件名校验 + 写入兜底)。
2. **官方源码入库**:`vendor/deepseek-harness-desktop` @ **v2.0.2**(浅克隆,gitignore 不入库,文档记录重下命令)。
3. **自建 exe**:`yarn install --mode=skip-build` → `yarn build` → `electron-builder --dir`
   → 产物 `vendor\...\dsh-plugin-desktop\dist\win-unpacked\DSH Desktop.exe`(552.7MB,与官方结构一致)。
4. **全部插件隔离装配**(方法 A,5 批):后端 → modlens 单包 → 模型/MCP 组 → 客户端 UI → 收尾;
   每批 staging 验证 + 合并 + 运行验证,26+ 插件全部在线。
5. **机制固化**(方法 A 安全隔离 / B 先移植后覆盖 / C 人工操作门)+ 全程文档。

## 三、如何重建(换机/回归)

```powershell
# 1. 源码与依赖
git clone --branch v2.0.2 --depth 1 https://github.com/anywhere-labs/deepseek-harness-desktop.git vendor\deepseek-harness-desktop
# 2. 构建(须在普通终端/PTY,harness shell 子进程受限):
powershell -File scripts\build-vendor.ps1     # yarn build
powershell -File scripts\package-vendor.ps1   # electron-builder --dir
# 3. 装配插件(每批走隔离,先退出 exe):
powershell -File scripts\staged-profile-assemble.ps1 -Batch 1 .. 5
# 4. 启动 dist\win-unpacked\DSH Desktop.exe
```
